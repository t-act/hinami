# MVP 要件定義

## 機能要件

### 認証
- メールアドレスのみで登録・ログインできる（パスワード不要）
- Magic Linkをメールに送信し、リンクをクリックするとログインできる
- セッションはCookieで管理し、有効期限は30日
- ログアウトできる

### ペアリング
- ユーザーは招待リンクを生成できる
- 招待リンクを受け取ったユーザーがリンクを踏むとカップルとして紐付く
- 1カップルは2人まで
- ペアリング前はカレンダーを閲覧・編集できない

### カレンダー
- 月単位でカレンダーを表示できる
- 前月・翌月へ移動できる
- 日付をタップすると、その日のイベント一覧を表示できる

### イベント
- イベントを作成できる（タイトル・カテゴリ・日付・時刻）
- イベントを編集できる（タイトル・カテゴリ・時刻）
- イベントを削除できる
- カテゴリは `mine`（自分）/ `partner`（パートナー）/ `together`（ふたり）の3種類
- カップル双方が同じイベントを閲覧できる

### データ永続化
- イベントはサーバー（Cloudflare D1）に保存される
- アプリを再起動してもデータが保持される

### PWA
- ホーム画面に追加できる（manifest.json）
- 直近のデータをオフラインで閲覧できる（Service Worker）

---

## 非機能要件

### パフォーマンス
- カレンダー初期表示: 2秒以内
- イベント作成のレスポンス: 1秒以内

### セキュリティ
- APIへのリクエストはセッションCookieで認証
- 自分のカップルのイベントのみ取得・更新可能（他カップルのデータにアクセス不可）
- Magic Linkは1回限り有効・有効期限15分

### 可用性・デプロイ
- Cloudflare Workers + Pages による低コスト運用
- ステージング環境と本番環境を分離

### 保守性
- フロントエンド・APIで型定義を共有（`packages/shared`）
- API変更時にフロントエンドの型エラーで検知できる

## スコープ外（MVP後）

- プッシュ通知
- イベントのリピート（繰り返し）
- コメント・リアクション機能
- 複数カップル対応
- 写真添付
- Google Calendar連携
